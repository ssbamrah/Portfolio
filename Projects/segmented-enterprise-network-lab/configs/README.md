# Configuration Files

Configuration files from the lab's routers and service hosts.

| Path | Contents |
|---|---|
| `routers/r1/`, `routers/r2/` | Open vSwitch SVI script, netplan, FRR/OSPF, DHCP relay, nftables firewall |
| `routers/systemd/` | `ovs-l3.service` unit that rebuilds the SVIs at boot |
| `services/bind-private/` | Private DNS: internal zone, reverse zones, AD SRV records |
| `services/bind-public/` | Public DNS for the DMZ |
| `services/dhcp/` | ISC DHCP server with per-segment scopes and reservations |

The host firewall configuration is generated by Ansible; see [`../automation/ansible/lab-config`](../automation/ansible/lab-config/).

## Notes

- These are lab configurations, not production templates.
- The OSPF MD5 key has been replaced with the placeholder `REPLACE_WITH_OSPF_MD5_KEY`.
- All addresses are private lab ranges.
